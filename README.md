# WinMNTC
## The windows maintance utility they never made

I created the script in DOS and then vibe coded it into PowerShell to give it a nice looking front end.

1. Update your windows and windows apps that are detected via winget.
2. Checks the windows system files (online).
3. Runs disk clean, defrag, checkdisk, and virus scan on the drives you specified.

   Has option to reboot when completed and write the output of the script to a file for review.
   Has the option to view output while running and see system usage while running.
