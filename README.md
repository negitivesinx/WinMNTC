# WinMNTC
The windows maintance utility they never made

I created the script in DOS and then vibe coded it into PowerShell to give it a nice looking front end.
It will update your windows and windows apps that are detected via winget.
It then checks the windows system files (online).
It then runs disk clean, defrag, checkdisk, and virus scan on the drives you specified.
It gives you the option to reboot when completed and write the output of the script to a file for review.
